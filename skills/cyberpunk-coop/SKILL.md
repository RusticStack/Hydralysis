# One system, then the library

`rusticre systems --game cyberpunk` is the list. Work one id. The coop code stays in the Night City Together repo. This skill is how you find the engine fact that code needs.

Order that matches the game a second player actually feels:

1. `player-body`, `player-animation`, `player-movement`. The puppet replays the owner. It does not run a second copy of the player's brain.
2. `world-streaming`. Each body loads the world around itself.
3. `new-game`, then `quests`, then `scenes`. A shared opening is the host's world facts at minute zero, including the prologue. Find the writer of those facts and cite it before syncing them. A scene does not play while the two quest journals disagree.
4. `vehicles`, `npcs`, `combat`. One owner. The receiver interpolates.

2.5 (exe 3.0.88.46235) already moved layouts, the script bundle, and hashes. `fingerprint` plus `hash` is how the next patch starts. A system row is `open` until an evidence row cites the function.

Animation that looks worse than another co-op mod is settled by a side-by-side of the two puppets and by the game's own graph inputs. Re-derive those inputs from `Cyberpunk2077.exe`. Do not decompile the other mod.
