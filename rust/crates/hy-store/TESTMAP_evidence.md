# Evidence / bundle test map (R-hy-storage, evidence fork)

Every test of `tests/test_evidence.py`, `test_evidence_model.py`, `test_evidence_bundle.py`, `test_evidence_parity.py` (and `test_bundles.py`, see the end), with its Rust counterpart.
Rust tests live in `rust/crates/hy-store/tests/` (`evidence_ledger.rs`, `bundle_tests.rs`, `evidence_parity.rs`, `diff_python.rs`). Run with
`RUSTC_WRAPPER= CC_KNOWN_WRAPPER_CUSTOM= cargo test -p hy-store` and set `HYDRALYSIS_TEST_ROOT` to a fast drive (SQLite commits fsync: 100-500 ms each on `E:`, 5 ms on `C:`).

Classification: **black-box** = uses only the public surface of `hydralysis.evidence` / `evidence_bundle` (plus raw sqlite3 on the ledger file), so it should pass unchanged against `HYDRALYSIS_IMPL=rust` once the PyO3 binding exposes that surface; every test is ALSO re-expressed in Rust with the same cases. **white-box** = reaches into internals (`SCHEMA`, `COLUMNS`, private `_subjects` / `_replay` / `_jsonl` / ... helpers) or asserts storage-internal rows; the Rust test is authoritative.

## tests/test_bundles.py (annotation bundles, PROTOCOL-3.md 4.9)

20 tests, not covered here: they exercise `hydralysis.annotations` export/import of *annotation* bundles against the fake daemon and the workcopy fixtures (`test_store_v3.Case`), which belong to the views/commits and query lanes. The file never touches `evidence.py` or `evidence_bundle.py`. Classes: `Export`, `ImportDryRun`, `ImportApply`. Owner: `R-hy-views/commits`. Its storage dependency (`durable`, `storelog`) is covered by hy-core / hy-store (see TESTMAP.md of the storage lane).

## Additions with no Python original
